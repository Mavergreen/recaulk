A program for Mac OS X 10.9 that calls `qos_class_self()` or `qos_class_main()` now builds with
Recaulk alone. `<pthread/qos.h>` declares both, and on 10.9 both report `QOS_CLASS_DEFAULT`, since
10.9 schedules every thread the same way. Newer macOS still answers with the system's own.
Before, `qos_class_self` had no declaration and `qos_class_main` did not exist, so a project such as
LLVM needed its own copies.
