C++ code built with Recaulk for Mac OS X 10.9 now catches pointers and member pointers by the rules
current macOS follows. A thrown `nullptr` is caught by a `catch` for a member pointer, a thrown
`int**` by a `catch (const int* const*)`, and a null pointer to a derived class is caught as a null
pointer to its base, not as the base's offset. 10.9's C++ runtime got these wrong. The rules hold for
the program or library that links Recaulk; the system's own libraries keep theirs.
