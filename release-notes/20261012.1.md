Claude Code on Mac OS X 10.9 could wait forever for a short-lived child process that exited before
Bun began watching it, leaving the child a zombie. The `kevent64` override dropped the kernel's
"no such process" answer when the caller gave it no room to report errors, which is how Bun
registers a process watch, so Bun never reaped the child. That answer now reaches Bun, as it does on
newer macOS.
