Programs built with Recaulk can ask Mac OS X 10.9 for its version through
`os_system_version_get_current_version`, which Swift's runtime uses for `if #available` and which 10.9
lacks. `<os/system_version.h>` declares it. On 10.9 it reads the version from
`/System/Library/CoreServices/SystemVersion.plist`. If it can't, it returns an error and leaves the
version unset. Newer macOS answers with its own.
