A program built for macOS 10.12 or later that brings its own memory allocator could crash on Mac
OS X 10.9 when Recaulk supplies its missing functions. Upstream's rustc is one, as rust's 10.9 build
runs it: it crashed about once in a thousand compiles. The first time such an allocator took a lock,
Recaulk looked for the system's own version of the lock. On 10.9 that search always fails, and the
failure needs memory, which re-entered the allocator mid-lock. On 10.9 Recaulk now uses its own
version without searching. Newer macOS still prefers the system's version.
