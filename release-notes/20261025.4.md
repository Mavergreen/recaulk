Recaulk now also ships `librecaulk-cxxabi-exports.a`, the pointer and member-pointer catch rules in a
form libcxx22 can export. It is for libcxx22's `libc++abi.1.dylib` alone; link nothing else with it.
Programs that use libcxx22, not only those built with Recaulk directly, can then catch a thrown
`nullptr` as a member pointer, an `int**` as a `const int* const*`, and a null derived pointer as a
null base pointer, as current macOS does.
